# react-native-coverage

Native code coverage tooling for **dedicated React Native test apps** (Pattern C): TurboModule flush, pull/export CLI, Expo config plugin, and docs.

This package is **New Architecture / TurboModule only**. It does not depend on `expo-modules-core`.
