---
title: Native code coverage for React Native
description: iOS, Android, and TypeScript code coverage from end-to-end tests in a dedicated React Native test app, with a CI gate for empty coverage.
---

<Warning>
  Install it in a [dedicated test app](/coverage#dedicated-test-app), never the app you ship. The flusher is a TurboModule, so the test app must run React Native's New Architecture.
</Warning>
